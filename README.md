# Mike Trout 打者分析

## 概要

MLB選手マイク・トラウトの2015年・2019年・2022年の打撃データを用いて、
キャリア最多となる45本塁打を記録した2019年シーズンの打撃内容について分析しました。

特に、40本塁打以上を記録した3シーズンを比較し、
「なぜ2019年のトラウトはキャリア最多の45本塁打を記録できたのか」を
打球の質や球種別のデータから分析しました。

## 分析テーマ

### 1. 2019年のトラウトは、どれほど凄かったのか？

2019年の打率、出塁率、長打率、OPS、本塁打数、四球数などから、
キャリア最多となる45本塁打を記録したシーズンの打撃成績と特徴を整理しました。

### 2. 2019年のトラウトは、何が違ったのか？

2015年・2019年・2022年の3シーズンを比較し、
Barrel%、Hard-Hit%、Launch Angle、Meatball%などから、
2019年の打球の質や特徴を分析しました。

特に、2019年は3シーズンの中でBarrel%が最も高い一方、
Meatball%が最も低かった点に注目しました。

### 3. 45本塁打は、どのような球種から生まれたのか？

Fastball、Breaking、Offspeedの球種別本塁打数を比較し、
さらに球種別のBA、xSLG、Whiff%から、
2019年のトラウトが各球種に対してどのような打撃をしていたのかを分析しました。

特に、2019年はBreakingやOffspeedに対する空振り率が低下し、
xSLGが上昇していた点に注目し、45本塁打を生み出した打撃の特徴を考察しました。

## 目的

PythonやSQLを用いたデータ取得・加工・可視化を行い、
MLBの打者データから選手の特徴や打撃スタイルを分析することを目的としています。
